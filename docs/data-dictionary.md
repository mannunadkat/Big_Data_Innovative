# Flight Data Dictionary & Schema Documentation

## Dataset Information
- **Dataset Name**: Airline Delay and Cancellation Data, 2009–2018
- **Source**: [Kaggle Airline Delay and Cancellation Data (2009-2018)](https://www.kaggle.com/datasets/yuanyupr/airline-delay-and-cancellation-data-2009-2018)
- **Origin**: Bureau of Transportation Statistics (BTS), U.S. Department of Transportation (DOT)

---

## HDFS Directory Layout
- **Raw Partitioned Data**: `/flights/raw/year=YYYY/YYYY.csv`
  - Replicated across DataNodes (`replication=2`, default block size 128 MB).
- **Cleaned Partitioned Data**: `/flights/cleaned/year=YYYY/part-*`
  - Output generated by map-only Hadoop Streaming jobs running `clean_mapper.py`.

---

## Raw Schema (Kaggle BTS Ingestion)
The raw dataset contains 28 columns (27 named BTS columns + 1 trailing empty/unnamed column):
```csv
FL_DATE,OP_CARRIER,OP_CARRIER_FL_NUM,ORIGIN,DEST,CRS_DEP_TIME,DEP_TIME,DEP_DELAY,TAXI_OUT,WHEELS_OFF,WHEELS_ON,TAXI_IN,CRS_ARR_TIME,ARR_TIME,ARR_DELAY,CANCELLED,CANCELLATION_CODE,DIVERTED,CRS_ELAPSED_TIME,ACTUAL_ELAPSED_TIME,AIR_TIME,DISTANCE,CARRIER_DELAY,WEATHER_DELAY,NAS_DELAY,SECURITY_DELAY,LATE_AIRCRAFT_DELAY,Unnamed: 27
```

### Raw Column Descriptions:
1. `FL_DATE`: Flight date (`YYYY-MM-DD`).
2. `OP_CARRIER`: IATA carrier code (e.g., `WN`, `AA`, `DL`).
3. `OP_CARRIER_FL_NUM`: Flight number.
4. `ORIGIN`: 3-letter IATA origin airport code.
5. `DEST`: 3-letter IATA destination airport code.
6. `CRS_DEP_TIME`: Scheduled departure time (local, `hhmm`).
7. `DEP_TIME`: Actual departure time (local, `hhmm`).
8. `DEP_DELAY`: Departure delay in minutes (negative = early).
9. `TAXI_OUT`: Taxi-out time in minutes.
10. `WHEELS_OFF`: Wheels-off time (local, `hhmm`).
11. `WHEELS_ON`: Wheels-on time (local, `hhmm`).
12. `TAXI_IN`: Taxi-in time in minutes.
13. `CRS_ARR_TIME`: Scheduled arrival time (local, `hhmm`).
14. `ARR_TIME`: Actual arrival time (local, `hhmm`).
15. `ARR_DELAY`: Arrival delay in minutes (negative = early).
16. `CANCELLED`: Cancelled flight indicator (`1.0` = cancelled, `0.0` = not cancelled).
17. `CANCELLATION_CODE`: Reason for cancellation (`A` = Carrier, `B` = Weather, `C` = NAS, `D` = Security, or empty).
18. `DIVERTED`: Diverted flight indicator (`1.0` = diverted, `0.0` = not diverted).
19. `CRS_ELAPSED_TIME`: Scheduled elapsed flight time in minutes.
20. `ACTUAL_ELAPSED_TIME`: Actual elapsed flight time in minutes.
21. `AIR_TIME`: Airborne time in minutes.
22. `DISTANCE`: Distance between airports in miles.
23. `CARRIER_DELAY`: Delay due to carrier in minutes.
24. `WEATHER_DELAY`: Delay due to weather in minutes.
25. `NAS_DELAY`: Delay due to National Aviation System in minutes.
26. `SECURITY_DELAY`: Delay due to security breach in minutes.
27. `LATE_AIRCRAFT_DELAY`: Delay due to late arriving aircraft in minutes.
28. `Unnamed: 27`: Trailing blank column.

## Cleaning & Filtering Rules
1. **Header Skipping**: Rows where the first field equals `"FL_DATE"` are identified and skipped (`HeaderSkipped`).
2. **Malformed Record Rejection**: Any row with fewer than 27 columns or missing essential departure timestamps is discarded (`DroppedMalformed`).
3. **Invalid Date Filtering**: Rows where `FL_DATE` cannot be parsed against `%Y-%m-%d` are dropped (`DroppedBadDate`).
4. **Code Validation**: Carrier must be alphanumeric; origin and destination must each be exactly 3 uppercase letters. Invalid codes are rejected (`DroppedBadCode`).
5. **Handling Cancelled Flights**:
   - Cancelled flights (`CANCELLED == 1`) are retained in the dataset (`CancelledKept`).
   - Delays for cancelled flights are standardized to `0` minutes.
   - Cancellation code defaults to `"NONE"` if unpopulated.
6. **Handling Missing Delays (Diverted / Incomplete Flights)**:
   - For non-cancelled flights, if `DEP_DELAY` or `ARR_DELAY` is missing/null (predominantly diverted flights), the row is dropped (`DroppedMissingDelay`).
7. **Default Delay Cause Imputation**: Missing values for the 5 delay breakdown fields (`CARRIER_DELAY`, `WEATHER_DELAY`, `NAS_DELAY`, `SECURITY_DELAY`, `LATE_AIRCRAFT_DELAY`) are imputed to `0`.
8. **Derived Features**:
   - `dep_hour`: Extracted as `(crs_dep_time // 100) % 24`.
   - `day_of_week`: Derived ISO day of week (`1`=Monday .. `7`=Sunday).
   - `is_delayed`: Target binary classification label defined by U.S. DOT standard (arrival delay >= 15 minutes on non-cancelled flights).
