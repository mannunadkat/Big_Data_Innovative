# Dataset Source
Download the US DOT Airline On-Time Performance dataset from:
https://www.kaggle.com/datasets/yuanyuwendymu/airline-delay-and-cancellation-data-2009-2018 (only the files `2009.csv` and `2010.csv` from that dataset were used).
Place raw CSV files here (this folder is gitignored — files stay local/on HDFS only).
